Professional Introduction

My progression through the Computer Science program at Southern New Hampshire University has strengthened both my technical capabilities and my understanding of how software engineering principles apply to complex, real-world problems. Throughout my coursework, I have developed experience in software architecture, algorithms and data structures, database management, secure coding, and artificial intelligence. More importantly, I have learned to approach software development as a disciplined engineering process that requires careful planning, evaluation, testing, and continuous improvement.

My academic experience builds upon a professional background involving project management, technical operations, and troubleshooting integrated systems. Working in these environments taught me the importance of identifying problems, coordinating resources, communicating expectations, and delivering reliable solutions. My computer science education has expanded that foundation by providing the programming knowledge and analytical methods needed to design and evaluate increasingly sophisticated computing systems.

Together, these experiences have shaped my professional interests in artificial intelligence, machine learning, autonomous systems, aerospace simulation, and scientific computing. This ePortfolio represents the intersection of those interests and demonstrates my development as a software engineer prepared to contribute to technically demanding, research-oriented projects.

Software Engineering and Design

My software engineering coursework strengthened my ability to design maintainable applications, evaluate existing implementations, and apply systematic development practices. Rather than viewing software as a collection of individual functions, I have learned to consider how architecture, testing, documentation, and error handling contribute to the reliability of a complete system.

The first enhancement in my CS-499 ePortfolio demonstrates this development through the restructuring of my Pirate Intelligent Agent project, originally developed in CS-370. The original artifact centered on a deep Q-learning implementation for navigating a maze. During the Software Design and Engineering enhancement, I reorganized the application into modular components responsible for the environment, intelligent agent, replay memory, configuration, training, and testing.

This restructuring improved separation of concerns and created a more maintainable foundation for subsequent enhancements. Adding input validation, strengthening error handling, and introducing automated testing also reinforced the importance of designing software that can be evaluated and extended without introducing unnecessary complexity.

My experience with full-stack application development has provided a complementary perspective by demonstrating how user interfaces, server-side logic, application routes, and data management components interact. Together, these projects have helped me develop a more comprehensive understanding of software engineering across different application architectures.

Data Structures and Algorithms

One of the most significant lessons from my computer science education has been recognizing that a working solution is not necessarily the most appropriate solution. Algorithm selection requires evaluating available information, computational complexity, data structures, and the trade-offs associated with different approaches.

My Algorithms and Data Structures enhancement demonstrates this principle through the implementation of A* pathfinding and breadth-first search (BFS) within the Pirate Intelligent Agent application. While the original project used reinforcement learning to develop navigation behavior through repeated interaction, the enhanced application introduced deterministic search techniques for evaluating paths through a known maze.

Implementing A* required the use of a priority queue, dictionaries, sets, and a Manhattan-distance heuristic. BFS provided a comparison using a first-in, first-out queue. In the controlled comparison maze, both algorithms identified an optimal path with a length and total cost of 14. A* explored 25 nodes, while BFS explored 26. These results provided a measurable comparison while also demonstrating that performance differences depend on the characteristics of the problem being evaluated.

Developing and testing these algorithms reinforced my ability to assess competing approaches rather than assuming one technique is universally superior. This analytical perspective is particularly relevant to my interests in autonomous navigation, artificial intelligence, and scientific simulation, where computational efficiency and solution reliability can significantly influence system performance.

Databases and Data Management

My database coursework and capstone development have demonstrated that effective data management involves more than storing and retrieving information. Reliable database systems require careful schema design, validation, integrity constraints, and consistent handling of application resources.

The third enhancement of my Pirate Intelligent Agent project introduced SQLite persistence for experiment results. I designed a relational structure that separates experiment runs from individual algorithm results, using primary and foreign keys to preserve relationships between records. I also incorporated database constraints, indexes, parameterized SQL statements, and explicit transaction and connection management.

This enhancement allowed the application to preserve actual results from reinforcement-learning experiments and deterministic pathfinding evaluations. Rather than relying exclusively on temporary console output, the application could retain structured information for later inspection and comparison.

The database enhancement also strengthened my understanding of testing and debugging. During development, automated tests exposed a database connection-management issue involving temporary files on Windows. Correcting that problem demonstrated the importance of considering resource lifecycles and platform-specific behavior when evaluating software reliability.

These experiences have provided a foundation for working with data-intensive applications, particularly those involving experiments, simulations, and machine-learning workflows.

Security and Responsible Computing

Security has become an essential part of how I approach software development. Throughout my coursework, I have learned that security should be incorporated into system design and implementation rather than treated as a final step after functionality is complete.

My capstone enhancements demonstrate this approach through defensive input validation, careful handling of invalid application states, parameterized database operations, and relational integrity constraints. These measures help reduce predictable failures and protect the consistency of application data.

My broader software engineering and secure coding coursework has also reinforced the importance of identifying potential vulnerabilities, evaluating dependencies, and considering the consequences of design decisions. In systems involving automation, artificial intelligence, or scientific research, reliable behavior and trustworthy data are particularly important because errors can influence downstream decisions and results.

I intend to continue applying a security-minded approach that considers not only whether software functions correctly, but also how it behaves when given unexpected inputs, encounters failures, or operates under changing conditions.
